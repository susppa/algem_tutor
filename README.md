# Алгем — База знаний по алгебре и аналитической геометрии

Электронный интерактивный справочник по курсу высшей алгебры и геометрии:
- **7 учебных модулей:** от матричных операций до векторных пространств и теории рангов;
- **Теория:** строгие определения, формулировки теорем, интуитивные объяснения («💡 Простыми словами») и полные математические доказательства;
- **Практика:** пошаговые алгоритмы решения типовых задач с подробными числовыми примерами (по задачнику Кострикина);
- **Поиск по курсу:** быстрый доступ к формулам, понятиям и теоремам.

---

### Структура проекта
- `index.html` — главная страница веб-приложения
- `css/style.css` — стили интерфейса (Academic Dark Theme)
- `js/app.js` — логика интерфейса, навигации и поиска
- `js/data-course.js` — учебные материалы курса (122 темы)
- `js/data-glossary.js` — глоссарий основных терминов
